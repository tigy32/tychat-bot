# tychat-bot

The runner library for Tychat personal bots and the two crates it builds
on, exported from Tychat commit `6cfd9c52371c31c1b4355acefd857cd2800ecacc`. This is a generated mirror:
Tychat is the source of truth and changes are made there.

- `crates/tychat-bot` — pairing, the owner chat, verification and
  encryption. Start with [its README](crates/tychat-bot/README.md).
- `crates/crypto` — the Tychat end-to-end encryption core.
- `crates/protocol` — the Tychat wire types.
